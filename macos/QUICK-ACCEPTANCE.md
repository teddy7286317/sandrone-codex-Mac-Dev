# 可直接貼上的 0.7.0 基準 Mac 手動驗收

本包：Mac 0.3.5、上游 v0.7.0／main `3a4f2cb`。**本次新版實機結果尚未取得，下列全部待驗收。** 這是完整主題包，與 #6 靜態背景包分開，不要同時運行。

```text
0. 先儲存工作、停止舊載入器，手動 Cmd+Q 完全退出 ChatGPT。
1. 把 Sandrone-ChatGPT-0.7.0-3a4f2cb-Mac-0.3.5-full-Test.app 放到固定位置，拖進 Dock，從它普通啟動；不必開 Terminal。
2. 等程式驗證通過，觀察同窗開屏及回首頁。主題／開屏稍晚出現是已知限制。
3. 關啟動器視窗，再點 Dock：只重開狀態視窗，不多開程序。
4. 首頁切換 Chat／Work，檢查選中、懸停、Tab 焦點；開一個可分享的對話，確認正文、輸入框和提示字可讀，輸入示例但不送出，並縮窄視窗檢查。
5. 開設定頁與模型選單，檢查一般／選中／懸停／鍵盤焦點；Esc 關閉後回到輸入框。不要求購買模型或更改敏感設定。
6. 重播開屏一次，檢查淡出後內容與焦點；若願意，另測 Esc、雙擊或兩次空格／Enter 跳過，沒測的方式記未測。
7. 停用：確認主題、重播 UI 與動畫清除；重新啟用：確認主題及重播恢復。
8. 停止並清理，等載入器結束；清理未確認時依提示處理。它不會代你退出 ChatGPT。儲存並 Cmd+Q 完全退出 ChatGPT，再從官方圖示開啟，確認原生外觀；官方圖示不會自動套用主題。
9. 可選錯誤恢復：官方 ChatGPT 已開著時點專用啟動器，應拒絕接管；儲存並完全退出後可重新嘗試。不要故意損壞官方包、素材或 Node，也不要關閉系統防護。
回報：macOS／ChatGPT 版本、包名、各步「通過／問題／未測」，問題所在畫面／狀態，願意分享的截圖或診斷。自然未發生的錯誤情境記未測。
```

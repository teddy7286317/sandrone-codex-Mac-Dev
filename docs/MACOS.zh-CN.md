# macOS 静态背景（实验性）

PR #6 已由上游 0.7.0 整合并保留 wsqUsaqi537 的原始提交与署名。这里是独立静态版；原版完整主题／开屏／Dock 控制来自已合并的 #7，见 [完整版](../macos/README.md)。两个入口不要同时运行。

此加载器将仓库中已有的 `themes/sandrone/background.png` 作为静态装饰显示在 ChatGPT/Codex 桌面窗口中。它不改写官方 `.app`、应用签名或账号设置；需要使用官方客户端和用户已有的登录状态。角色图片与其衍生素材不适用代码的 MIT 许可，权利和使用限制见 [素材权利说明](../ASSET-LICENSE.md)。

## 范围和要求

- macOS，官方应用位于 `/Applications/ChatGPT.app`，且其中包含 `Contents/Resources/electron.icns`。其他安装路径和其他版本尚未验证。
- Node.js 24 或更新版本，能在运行构建脚本的终端中通过 `node` 找到。启动器记住构建时找到的 Node 路径；以后移动或删除该 Node 版本时需重新构建。
- 这是静态背景，不包含 Windows 版本的开屏动画、签名、主题菜单、启动进度或重播功能。背景层会在窄窗口或对话框打开时隐藏；界面结构变化可能影响显示。
- 可访问本仓库中的图片素材；如果仓库放在“文稿”等受保护目录，终端可能需要获得 macOS 的相应目录访问权限。

## 本机构建启动器

在仓库根目录的终端中运行：

```sh
zsh ./Build-Mac-Static.command
```

默认脚本在临时目录构建，并创建 `~/Applications/桑多涅 ChatGPT.app`。如果目标已存在，它会停止而不会覆盖；请自行移走旧版本再重建。构建时从用户本机已安装的官方应用读取图标，仓库不再分发该图标。生成的应用仅使用临时自签名，未经过 Apple 公证。构建只编译和复制，不启动官方客户端。

维护回归可指定不安装到 Applications 的输出，并可用自己的图标（路径必须是 .icns）：

```sh
zsh Build-Mac-Static.command --output "$PWD/dist/My-Static-Test.app" --icon /path/to/Own.icns
```

新包附 LICENSE、素材权利、第三方说明、#6 来源与 upstream/build manifest。输出已存在时拒绝覆盖；不把 Node、官方程序、账号或 profile 打包。

先保存工作并完全退出 ChatGPT，再打开生成的启动器。可以把该启动器拖入 Dock；它是独立的启动程序，实际运行的 ChatGPT 可能在 Dock 显示另一个图标。首次启动失败时可从终端运行以下命令查看报错：

```sh
node ./macos/static/macos-skin.mjs
```

如果应用已经在运行，加载器会拒绝启动第二个实例；请先手动退出，加载器不会强制关闭正在进行的工作。

## 安全和恢复

加载器在启动的应用中启用仅监听 `127.0.0.1` 的 Chromium 调试接口。**本机其他进程仍可能连接该接口，读取或操控调试中的应用**，因此请仅在信任当前设备和本机其他进程的情况下使用。退出 ChatGPT 才会关闭该接口；只关闭加载器不保证调试接口关闭。该方法依赖非公开 UI 结构和调试行为，应用更新后可能失效。

要恢复官方外观，保存工作、完全退出通过加载器启动的 ChatGPT，然后通过官方应用图标正常启动。要移除启动器，将 `~/Applications/桑多涅 ChatGPT.app` 移到废纸篓即可；原仓库和官方应用不会因此被删除。
